# 🚀 API Automation Testing Framework

A robust and scalable API testing framework built with **Python**, **Pytest**, and **Requests**, featuring comprehensive and visually appealing test reports generated by **Allure**.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Testing Framework:** Pytest
- **HTTP Library:** Requests
- **Reporting:** Allure Report
- **Target API:** [Reqres.in](https://reqres.in/) (Mock API for testing)

## ✨ Features
- ✅ Automated API tests for GET, POST, and negative scenarios (e.g., 404 Not Found).
- ✅ Data validation using `assert` statements (Status Codes, JSON payloads).
- ✅ Professional HTML test reports with step-by-step execution details via Allure.
- ✅ Clean and modular code structure following best practices.

## 📋 Prerequisites
Before running the tests, ensure you have the following installed:
1. **Python 3.x** ([Download here](https://www.python.org/))
2. **Java JDK 17+** (Required for Allure Report) ([Download here](https://adoptium.net/))
3. **Allure Commandline** ([Download here](https://github.com/allure-framework/allure2/releases))
